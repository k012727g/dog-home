# 音源資料夾 audio/

繪本朗讀用的錄好的聲音檔（mp3，單聲道 48kbps）。

## 遊戲正在用的（放在 audio/ 第一層）
遊戲會自動讀這一層的 mp3，有錄音就播錄音，沒有才用裝置內建的聲音。檔名規則是主程式定好的：
- 繪本：`<故事id>-<頁>-en.mp3`、`<故事id>-<頁>-zh.mp3`（頁從 1 開始），例：`snow-1-en.mp3`
- 英文單字與繪本問答答案：`<單字>.mp3`，例：`apple.mp3`
- 目前：17 本繪本（V4，每本 12 頁）全部頁面 408 個＋108 個單字，共 516 個。英文是 Ana（美國小女孩），中文是曉臻（台灣姊姊），都是微軟語音（edge-tts）。
- 還沒有錄音的：繪本問答的題目句子（會用裝置內建聲音）。

## 試聽用（放在子資料夾）
`audio/<故事 id>/<聲音>/<語言>_<頁>.mp3`
- 頁 0 是書名，1～8 是內頁。
- 語言：`en` 英文、`zh` 中文。
- 目前只有 `snow`（白雪公主），給 `beta/story_voice_test.html` 試聽用。

## 聲音來源與授權
| 資料夾開頭 | 來源 | 授權 |
|---|---|---|
| `kokoro-` | Kokoro-82M 語音模型，用 GitHub 上的 thewh1teagle/kokoro-onnx 產生 | Apache-2.0，可以自由使用 |
| `edge-` | 微軟線上神經語音，用 GitHub 上的 rany2/edge-tts 工具產生 | 微軟沒有公開授權，只適合家裡自己用，不要拿去公開散布或商用 |

## 重新產生
選定聲音後，可以用同樣的方法一次產生 17 本書的全部頁面。
