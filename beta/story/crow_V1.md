# 烏鴉喝水 The Crow and the Pitcher｜故事稿 V1（2026-11-22）

規格見 `STORY_GUIDE.md` 和 `briefs/story_brief.md`。這一版是重寫 V4（content.js 的 `crow`），頁數不變（12 頁）。
這是**故事稿**（給 Kevin 看、給美術畫）。Kevin 說 OK 後，才寫進 `content_beta_V?.js`。

## 劇情大綱（一句話）
好熱的一天，烏鴉好渴，找到一個水壺，可是水太少，嘴巴碰不到；推也推不倒。她想到好辦法：一顆一顆把石頭丟進去，一、二、三……十！水升到最上面，她咕嚕咕嚕喝個夠。一點一點來，好辦法就會成功。

## 這一版用了哪些繪本技巧
| 技巧 | 用在哪 |
|---|---|
| 數數 | one 到 ten（P07–P10），用到單字庫的數字 |
| 狀聲詞 | Plop!、Gulp! |
| 翻頁驚喜 | P09 七、八、九…… → P10 十！ |
| 道理收尾 | 一點一點來 |

## 和 V4 的差別
- 新書。故事很短，用數數撐到 12 頁。
