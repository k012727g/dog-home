# 小紅帽 Little Red Riding Hood｜故事稿 V1（2026-11-22）

規格見 `STORY_GUIDE.md` 和 `briefs/story_brief.md`。這一版是重寫 V4（content.js 的 `red`），頁數不變（12 頁）。
這是**故事稿**（給 Kevin 看、給美術畫）。Kevin 說 OK 後，才寫進 `content_beta_V?.js`。

## 劇情大綱（一句話）
小紅帽答應媽媽「不要離開小路」，卻被大野狼騙去摘花；大野狼搶先到奶奶家，三個「好大的…」之後露出真面目，小紅帽大喊救命，獵人趕走大野狼。從此她都走在小路上。

## 這一版用了哪些繪本技巧
| 技巧 | 用在哪 |
|---|---|
| 前面埋、後面收 | P02 媽媽說 Stay on the path → P04 她離開小路 → P12 她每天都走小路 |
| 重複句 | Tip, tap（P03、P12）；So I can …（P07、P08、P10） |
| 三次法則 | ears → eyes → **teeth**（第三次不一樣：大野狼不回答，直接翻頁） |
| 翻頁驚喜 | P09 停在 teeth，翻到 P10 才「So I can EAT you!」 |
| 圖說、文字不說 | 獵人從 P03 就在背景出現（文字沒提），P11 他「聽到了」才合理 |
| 身體單字 | ear、eye 是 WORD_BANK 的字，問答可以用 |

## 和 V4 的差別
- 新增：媽媽的叮嚀、ears 那一頁、Help!、結尾收伏筆。
- 奶奶從衣櫃出來不另外畫一頁：P12 奶奶坐在桌邊就表示她平安了（一頁最多 4 個角色或道具）。
- 拿掉：「大野狼跑去奶奶家」和「把奶奶關進衣櫃」合成一頁；吃蛋糕併進結尾。
- 獵人不帶槍或刀，只帶號角和提燈（溫和）。
