# 繪本故事寫作規則＋給美術的標注格式（V1，2026-11-22）

這份是「寫故事的人」和「畫圖的人（美術 LLM，分支 `claude/wizardly-allen-hr44r9`）」共用的規格。
工作分工見 `CLAUDE.md` 第 6 節、`briefs/story_brief.md`（這份規格和它一致；有衝突時以 brief 為準）。

**流程**：①寫故事稿 `beta/story/<id>_V?.md` → ②Kevin 在預覽網頁看、說 OK → ③美術對話照稿裡的 CHAR／BG／PROP 表畫新的圖 → ④繪本對話把文字和畫面寫進 `content_beta_V?.js` 交付。

預覽網頁：`beta/story/story_preview.html`（讀這個資料夾的 .md，寫好新的一本要在網頁的 BOOKS 清單填上檔名）。
每一本書一個檔案：`beta/story/<書的id>_V<版本>.md`（例：`red_V1.md`）。美術只要讀那一本的檔案就能畫。

## 1. 故事怎麼寫（參考國外繪本的寫法）

| # | 規則 | 為什麼／參考 |
|---|---|---|
| 1 | **一頁只做一件事**：一個動作或一句對話。 | 小小孩一次只跟得上一件事。 |
| 2 | **英文一頁 ≤ 12 個字**（國小一、二年級的字）；**中文 ≤ 30 字**，繁體、台灣用語。WORD_BANK 裡的字（顏色、數字、身體、動作）優先。 | 孩子 6 歲、還不識字，是**聽**故事；短句才聽得懂、跟得上。 |
| 3 | **三次法則**：重要的事做三次，第三次不一樣。 | 《三隻小豬》《金髮女孩》；小孩會開始猜下一句。 |
| 4 | **重複句（refrain）**：每本至少一句會重複出現的話或聲音。 | 《Brown Bear, Brown Bear》《We're Going on a Bear Hunt》：小孩會跟著唸。 |
| 5 | **翻頁驚喜**：緊張的那一頁停在半句或問句，翻過去才揭曉。 | 繪本最強的效果：讓孩子自己「翻」出答案。 |
| 6 | **文字不說的，讓圖說**：例如壞人躲在背景、幫手早就出現在遠處。 | 《Rosie's Walk》：文字很少，笑點全在圖裡。 |
| 7 | **前面埋，後面收**：開頭說的話，結尾要用到（例：媽媽說「別離開小路」→ 結尾她記住了）。 | 結構完整，結尾有「啊！」的感覺。 |
| 8 | **狀聲詞**：Knock, knock! Splash! Tip, tap. | 好唸、好玩、好錄音。 |
| 9 | **溫和**：可怕的事點到為止，不寫吃掉、死掉的細節；結局一定平安。 | 對象是 6 歲小孩。 |
| 10 | **中文是自然的翻譯**，不是逐字翻；也要短。 | 家長唸中文時要順口。 |
| 11 | **一頁最多 4 個角色或道具**（背景不算），重點角色放大、放中間。 | 手機上畫面很小。 |

### 每本的結構（12 頁；錄音照頁碼存，頁數不能改）

| 頁 | 用途 |
|---|---|
| 1 | 認識主角（他是誰、有什麼特徵） |
| 2 | 出發的原因／規則（埋伏筆） |
| 3–5 | 出發、遇到問題 |
| 6–9 | 越來越緊張（三次法則放在這裡） |
| 10 | 翻頁驚喜／最高點 |
| 11 | 解決 |
| 12 | 平安結局＋收伏筆 |

問答 3 題：1 題顏色或數字、1 題「誰」、1 題「什麼東西」。答案和選項都要是 QPIC 有圖的字；沒有圖的要標「需新圖」。

## 2. 給美術的標注格式

每本書檔案裡有四張表＋每頁一段。**ID 是寫故事和畫圖共用的名字**，美術做出來的函式名稱請用同一個 ID（或標出對應）。

### 2-1 角色表 `CHAR`
| 欄位 | 說明 |
|---|---|
| ID | 例 `red`、`wolf`（現有的寫出 art.js 名稱，例 `G.red`、`SK.wolf`） |
| 外型 | 年紀感、體型、髮型、衣服 |
| 固定顏色 | **劇情會用到的顏色一定要寫色碼**（例：問答問斗篷顏色） |
| 需要的表情 | 只列這本書會用到的 |
| 需要的姿勢 | 走、跑、敲門、躺著、躲… |
| 狀態 | 現有／要改／新做 |

### 2-2 背景表 `BG`
ID、地點、時間（白天／晚上）、必要元素（劇情會用到的，例如「看得見的小路」）、現有對應（`HOME`、`FOREST`、`GRASS`、`FLOOR`…）。

### 2-3 道具表 `PROP`
ID、樣子、在哪幾頁、劇情用途、狀態（現有 `SK.xxx`／新做）。

### 2-4 每頁
```
### P03
EN: …
ZH: …
劇情推進：這一頁讓故事往前走了什麼（一句話）
畫面：背景 ID ／ 構圖（遠景、中景、特寫）
角色：ID＠位置（左／中／右）— 動作 — 表情
道具：ID＠位置
動畫：an-bob / an-shake / an-walk / an-knock / an-pop（現有的動畫名稱）
翻頁：有沒有翻頁驚喜
找找看：這頁藏起來的小東西（可不填）
聲音：沿用現有錄音／要重錄
```

### 2-5 畫面座標習慣（現有 art.js）
- 畫面寬 320、高約 200；地面線 y≈165。左＝x 40–110，中＝x 140–190，右＝x 210–290。
- 角色大小預設 1；要「靠近、特寫」時用放大（`s:1.4` 以上）或另畫特寫圖。
- 美術風格（文具風 1／2／3、蠟筆）由美術分支決定；本規格**只寫要畫什麼**，不寫風格。

## 3. 注意

- 改了英文或中文句子，`audio/` 裡那一頁的錄音就要重錄（主程式對話負責）；每頁都標「沿用」或「要重錄」。
- 書的 `id` 不能改；畫面只能用 art.js 裡**已經有**的名稱。新的角色道具先在故事稿標「新做」，美術畫好前 content.js 先用現有的代替。
- 不要畫任何現有的商業角色（迪士尼版小美人魚、灰姑娘等的造型）。古典童話本身可以用，造型要原創。
- 不確定的事寫「無法確定」。
