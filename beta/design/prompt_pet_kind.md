# 給「主程式對話」的 prompt：家長設定可以選寵物（小狗／小飛龍）

> 整段貼給主程式對話。美術需要的部分在 `art_beta_V5.js`，已經做好也測過。

---

請在**家長設定**加一個「寵物種類」，可以選**小狗**或**小飛龍**。每個家庭（每個小孩）可以選不同的寵物，選擇跟著存檔一起同步。照 `CLAUDE.md` 第 2 節的流程做（先跑點擊測試、做下一版、比對、只推 beta）。

- 美術用 **`art_beta_V5.js`**，繪本用 **`content_beta_V5.js`**。

## 美術已經準備好的（art_beta_V5.js）
- `pupSVG(stage, opts)`：**會自動照 `S.pet.kind` 畫小狗或小飛龍**。沒設定或值不對，就畫小狗。也可以用 `opts.kind:'dog'|'dragon'` 指定。首頁、洗澡、地圖、升級畫面、英文動作單字圖這些畫寵物的地方，都不用改。
- `petKind()`：目前存檔的寵物種類，回傳 `'dog'` 或 `'dragon'`。
- `PET_KINDS`：
  - `PET_KINDS.dog = {name:'小狗', stages:['小狗寶寶','小狗','大狗狗'], coats:COATS}`
  - `PET_KINDS.dragon = {name:'小飛龍', stages:['小龍寶寶','小飛龍','大飛龍'], coats:DRAGON_COATS}`
- `petSVG(kind, stage, opts)`：指定種類畫，給選擇按鈕的預覽圖用。
- `coatName(毛色鍵, kind)`：美容院的毛色名稱。
  - 小狗：赤、奶油、芝麻、黑、白
  - 小飛龍：薄荷龍、薰衣草龍、天空龍、夜空龍、雪白龍
  - 毛色鍵兩種寵物共用，所以 `S.pet.look` 不用改。
- `icon('petHead')` 會自動換成目前寵物的頭像。
- 小飛龍的翅膀會拍動（`dg-wing`，已經放在 DOGART.css）。

## 要做的事（行號都是 index_beta_V6.html 的）
1. **存檔欄位** `S.pet.kind`：值是 `'dog'` 或 `'dragon'`。
   - `DEFAULT()` 的 pet 加上 `kind:'dog'`。
   - `normalize()` 裡，值不是這兩個就設成 `'dog'`。
   - 舊存檔會自動變成小狗，等級、考卷、獎品都保留。
   - 這個欄位在 `S` 裡，會跟著 Firebase 同步，每個家庭各自一份。
2. **家長設定的畫面**：放在「小狗與考卷」分頁（1041 行）的「小狗的名字」（1049 行）旁邊，標題「寵物種類」。
   - 兩個大按鈕，各放一張預覽圖：`petSVG('dog',2,{happy:true})`、`petSVG('dragon',2,{happy:true})`，下面寫「小狗」「小飛龍」。目前選的那個要有明顯的框。
   - 按下去先問：「要換成小飛龍嗎？等級、考卷、獎品都會保留。」按確定後執行：`S.pet.kind=…; addLog('🐉 寵物換成小飛龍'); save(); pupKey=''; renderAll();`
   - 分頁名稱「小狗與考卷」改成「寵物與考卷」，「小狗的名字」改成「寵物的名字」。
3. **畫面快取要把種類算進去（一定要做）**：2138 行 `key!==pupKey` 那一段，key 要加上 `S.pet.kind`。
   - 美術這邊實測過：key 沒有種類的話，換寵物後畫面不會變，要重新整理才會變。
   - 這樣另一台裝置透過 Firebase 換寵物時，這台也會跟著更新。
4. **等級名稱**：`STAGES[i].name`（1876、2233、2244 行）改成 `PET_KINDS[petKind()].stages[i]`。`STAGES` 的 min 和 scale 不用動。
5. **美容院**：3181 行顯示毛色名稱、寫紀錄的地方，`COATS[key][3]` 改成 `coatName(key)`。
6. **文字**：加一個 `petWord()`，回傳 `PET_KINDS[petKind()].name`，然後把孩子看得到的「小狗／狗狗」換掉（清單在下面）。
