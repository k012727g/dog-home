# 備份資料夾

小狗的家的存檔備份。每份檔名是 `family-<代碼前 2 碼>xxxx-<日期>.json`。

## 怎麼還原
1. 打開遊戲 → 家長 → 「備份與其他」→「從備份還原」。
2. 選這個資料夾裡的檔案（先從 GitHub 下載到平板）。
3. 確認日期後，進度會換成備份的內容，同一個家庭的其他裝置也會一起同步。

## 注意
- 這個 repo 是公開的（Kevin 2026-11-22 決定備份放這裡）。任何人都看得到這裡面的進度內容。
- **家庭代碼一律遮住**（只留前 2 碼加 `****`）。還原用不到代碼，所以不影響備份。
- 換正式版之前，每個小孩的存檔都要再備份一次。
